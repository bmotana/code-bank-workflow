# Code Bank Workflow

A comprehensive learning system for mastering code snippets through structured practice.

## Features

- Interactive recall-based practice games
- Notion database integration for snippet management
- LLAMA-powered Feynman technique explanations
- Anki flashcard export with customizable templates
- Progress tracking and session resume capability
- Fallback options for API dependencies
